# 🏥 Hospital Emergency Room Dashboard | Excel Data Analytics Project

## 📌 Project Overview

This project focuses on analyzing hospital emergency room data using Microsoft Excel. I created an interactive dashboard to understand patient visits, waiting time, patient satisfaction, admission status, gender distribution, age groups, and department referrals.

As a Data Analyst fresher, I worked on presenting data in a clear and visual format to make key information easier to understand and support data-driven decision-making.

## 🎯 Project Objectives

- Analyze the number of patients visiting the emergency room.
- Monitor average patient waiting time and satisfaction score.
- Compare admitted and non-admitted patients.
- Understand patient distribution by age group and gender.
- Identify the most frequently referred departments.
- Track daily trends and monthly performance using interactive filters.

## 🛠️ Tools & Skills Used

- **Microsoft Excel**
- Pivot Tables and Pivot Charts
- Interactive Slicers and Filters
- Data Visualization
- KPI Reporting
- Dashboard Design
- Data Analysis and Interpretation

## 📈 Dashboard Features

### 1. Patient Overview
Displays the total number of patients, average waiting time, and patient satisfaction score.

### 2. Admission Status Analysis
Compares admitted and non-admitted patients to understand patient admission patterns.

### 3. Age Group Analysis
Shows patient distribution across age groups, helping identify which age groups account for more emergency room visits.

### 4. Gender-wise Analysis
Visualizes the distribution of male and female patients.

### 5. Patient Attendance Status
Compares delayed and on-time patient attendance to help monitor service timeliness.

### 6. Department Referral Analysis
Displays patient referrals across departments, including General Practice, Orthopedics, Physiotherapy, Neurology, and Cardiology.

### 7. Time-based Analysis
Uses date, month, and year filters to explore patient trends and compare reporting periods.
